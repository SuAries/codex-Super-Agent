# Security / 安全报告

Please do not disclose a suspected vulnerability, exploit details, credentials, or sensitive logs in a public issue or pull request. If GitHub private vulnerability reporting is enabled for this repository, use its **Security → Report a vulnerability** option. If it is not enabled, ask a maintainer for a private reporting channel without posting the vulnerability details publicly. Do not assume a specific contact address or response time.

In a private report, describe the affected version, environment, minimal reproduction, impact, and any relevant mitigations. Redact credentials, account data, personal paths, and unrelated project information. Do not send complete logs containing sensitive data. Allow the maintainer time to investigate and coordinate disclosure.

请勿在公开议题或拉取请求中披露疑似漏洞、利用细节、凭据或敏感日志。若仓库已启用 GitHub 私密漏洞报告，请通过 **Security → Report a vulnerability** 提交；若未启用，请先向维护者询问私密联系渠道，不要公开漏洞细节。仓库不承诺固定联系方式或响应时间。

私密报告中请提供受影响版本、环境、最小复现、影响及已知缓解措施，并遮盖凭据、账户数据、个人路径和无关项目资料。请留出调查与协调披露的时间。
